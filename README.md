### About

Custom build of stock windows flutter application shell experience. Stock generated shell contains the infamous never-fixed windows titlebar scaling bug (naturally, because it calls Windows to draw its client), present since W7 as far as my memory serves. See the Windows 7 window theme example to illustrate the bug
